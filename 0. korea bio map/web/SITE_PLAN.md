# K-Bio Community · 1단계 구성안

가칭 **K-Bio Community**. 대학원 진로를 고민하는 사람이 "이 연구실 졸업생은 어디로 갔나"를 찾는 사이트.

## 1. 목표와 대상

- **대학원 준비생**: 연구실 선택에 필요한 졸업 기간, 진로, 연구 지표를 본다.
- **석사 졸업 후 국내 박사로 옮기려는 사람**: 연구실별 졸업생 진로와 교수 배출 현황을 본다.
- **대학원생**: 같은 정보를 보고 연구실 비교에 참여할 수 있다 (2단계 커뮤니티).

## 2. 공개 범위 원칙

- 졸업생 개인 이름, 사진, 개인 연락처는 공개하지 않는다. 통계로만 보여준다.
- 교수 이름과 소속은 공개한다. 교수 개인 페이지 링크는 원본 출처로 연결한다.
- 교수가 된 제자 이름은 졸업생 페이지에서 확인된 경우에만 표시하고, 출처를 함께 적는다.
- 은퇴한 교수는 별을 흐리게 표시하고 "은퇴"를 붙인다. 계보는 그대로 보인다.
- 정정 요청 경로를 페이지에 둔다.

## 3. 화면 구성 (지도형)

메인은 지금 있는 3D 지도다. 검색과 필터는 지도 위에 얹는다.

| 영역 | 내용 |
|---|---|
| 상단 탭 | 지도 · 검색 · 순위 · 필터 · 비교 |
| 지도 | 교수 = 별, 크기 = 점수, 색 = 분야. 별을 누르면 상세 카드 |
| 검색 | 이름, 대학, 분야, 연구 키워드 |
| 순위 | 졸업 기간, 학생당 논문, 교수 배출 등 기준별 순위 |
| 필터 | 분야, 산학연병, 지역, 기술, 직위, 연구실 졸업생 기준 |
| 비교 | 교수 최대 3명을 나란히 표로 보기 (아래 4장) |
| 상세 카드 | 연구실 통계, 졸업생 진로, 계보, 논문 실적, 링크 |

모바일에서는 3D 지도가 무거우므로, 같은 데이터를 목록과 2D 지도로 대체하는 화면을 함께 둔다.

## 4. 비교 탭

- **담기:** 상세 카드의 "비교에 담기"로 최대 3명까지 담는다.
- **항목:** 학과, 박사·석박통합·석사 평균 졸업 기간, 졸업생 수, 교수가 된 졸업생, 기업 진출 졸업생, 학생당 논문, 학생당 1저자 논문, 논문 영향력(FWCI), 지도 속 교수가 된 제자, 최근 5년 논문, h-index.
- **강조:** 졸업 기간은 짧을수록, 나머지는 많을수록 좋은 값을 노란색으로 표시한다. 값이 없는 칸은 0이 아니라 "정보 없음"으로 두어 이기지 않게 한다.
- **기간:** 연구실 졸업생 기준을 최근 5년과 전체 중에서 고를 수 있다.
- **공유:** 주소에 `#compare=P0001,P0002`로 담겨서 링크로 같은 조합을 공유한다.

구현 상태: `web/index.html`에 들어 있음 (커밋 385c38b).

## 5. 데이터와 갱신

- 데이터는 지금처럼 `data/`의 CSV에서 만들어진다. 파이프라인이 `web/network-data.js`를 다시 쓴다.
- 갱신 주기는 **주 1회 자동 갱신**, 정정은 들어오는 대로 수동 갱신한다.
- 졸업생 수집과 OpenAlex 집계는 기존 워크플로를 그대로 쓴다.

## 6. 기술 방향

- **1단계:** 정적 사이트 (GitHub Pages). 로그인 없음, 서버 없음. 검색과 지도, 비교는 브라우저에서 처리.
- **2단계 (커뮤니티):** 글쓰기, 댓글, 후기가 필요해지는 시점에 로그인과 DB를 붙인다. 이때 앱 방식을 검토한다.
- 1단계 구조는 2단계를 막지 않도록 데이터와 화면을 분리해 둔다.

## 7. 2단계 커뮤니티 (나중에)

- 연구실 후기, 질문 게시판, 진로 상담 글
- 로그인 후 정보 수정 요청과 정정 제보
- 김박사넷처럼 교수 검색과 후기를 함께 두는 구조를 참고

## 8. 열린 질문

- 사이트 이름과 도메인 (아래 도메인 후보 참고)
- 모바일 화면을 1단계에 넣을지, 목록형 대체 화면만 먼저 만들지
- 졸업생 이름을 교수가 된 경우에만 공개하는 범위를 페이지에 어떻게 적을지
